# Imposter

Imposter is a game where everyone except the Imposter is asked the same question, and the Imposter is asked a similar but different question. Everybody says their answers, and people try to guess who the Imposter is. Instead of a real person having to ask the questions, this app does it for you. 

# How to play
Open the page (`npx serve` or `python -m http.server` in the directory index.html is in is fine). Put in the number of people playing, and pres start.
